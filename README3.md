# Task 3 - API Security Risk Analysis

## Objective
The objective of this task is to analyze API security risks, identify vulnerabilities, and understand authentication, authorization, and data exposure issues.

## API Endpoints Tested
- /users
- /posts
- /comments

## Tools Used
- Postman
- Browser DevTools
- JSONPlaceholder Public API
- PDF Documentation

## Security Risks Identified
- Missing authentication
- Weak authorization
- Data exposure risks
- No visible rate limiting
- Input validation issues

## Risk Classification
- High Risk
- Medium Risk
- Low Risk

## Remediation Steps
- Implement authentication tokens
- Add access control
- Enable rate limiting
- Validate user inputs
- Restrict sensitive data exposure

## Conclusion
This task helped in understanding API security risks and the importance of securing endpoints through authentication, authorization, and proper validation techniques.
